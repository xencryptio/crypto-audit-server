Agent Setup and Management Documentation

                
Detailed instructions on how to set up and manage the Crypto Audit Agents for Linux and Windows operating systems.

            


            

                
🐧 Section 1: Linux Agent Setup

                
    
                    
  1. Go to the **Agent Downloads** tab.
    2. 
                    
  2. Under **Linux Agent**, click on the 📦 Download All as ZIP button.
    3. 
                    
  3. Navigate to your downloads directory and open a terminal there.
    4. 
                    
  4. Unzip the downloaded file using the command: unzip Linux_Agent.zip
    5. 
                    
  5. Verify the presence of the following files after extraction:
                        
      
                            
    • crypto-agent.service
      • 
                            
    • crypto_agent_service.py
      • 
                            
    • install_crypto_agent.sh
      • 
                            
    • linux_server.py
      • 
                            
    • uninstall_crypto_agent.sh
      • 
                        
    
                    
    6. 
                    
  6. Make the installation script executable: chmod +x install_crypto_agent.sh
    7. 
                    
  7. Run the installation script with elevated privileges (sudo) to start the agent: sudo ./install_crypto_agent.sh
    8. 
                

                
To Uninstall the Linux Agent:

                
    
                    
  1. Make the uninstallation script executable: chmod +x uninstall_crypto_agent.sh
    2. 
                    
  2. Run the uninstallation script with elevated privileges (sudo): sudo ./uninstall_crypto_agent.sh
    3. 
                

            


            

                
🪟 Section 2: Windows Agent Setup

                
    
                    
  1. Go to the **Agent Downloads** tab.
    2. 
                    
  2. Under **Windows Agent**, click on the 📦 Download All as ZIP button.
    3. 
                    
  3. Navigate to your downloads directory and extract the ZIP file.
    4. 
                    
  4. Verify the presence of the following files after extraction:
                        
      
                            
    • build_executables.bat
      • 
                            
    • config_editor.py
      • 
                            
    • crypto_agent_service_windows.py
      • 
                            
    • install.py
      • 
                            
    • quick_config.bat
      • 
                            
    • uninstall.py
      • 
                            
    • windows_audit.py
      • 
                        
    
                    
    5. 
                    
  5. Open **Command Prompt (CMD)** or **PowerShell** in the extracted directory and run the installation script to set up the agent service: python install.py or just install.py
    6. 
                

                
To Remove the Windows Agent:

                
    
                    
  1. In Command Prompt or PowerShell, run the uninstallation script: python uninstall.py or just uninstall.py
    2.
